CONCOURSE PRIVACY POLICY

Concourse is a private Mac app used only by its owner. This policy explains how it handles Google user data.

  • What it reads: Concourse asks Google for read-only Gmail access (the gmail.readonly scope). It reads message headers, labels, and short previews so it can show the inbox on a board.
  • What it never does: It never sends, deletes, archives, labels, or marks mail as read.
  • Where data goes: Mail data is shown on the owner's Mac and kept in memory only. It is not stored on any server, shared, sold, or used for advertising. The only network calls the app makes go to Google.
  • Sign-in tokens: Stored in the macOS Keychain on the owner's Mac. Access can be removed at any time from the Google Account security page.

Concourse's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
